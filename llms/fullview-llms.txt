# Fullview

> Fullview is a customer-support platform combining cobrowsing (agents view and control a customer's browser session in real time, directly from a help-desk ticket) and session replays (automatic recording of user sessions with console, network and JavaScript-error capture). Integrates one-click with Zendesk, Intercom, Salesforce and HubSpot.

## APIs
- [Bug Report API](https://support.fullview.io/en/articles/11552509-report-a-bug-api-endpoints): Start/stop a session-replay bug recording for an identified user (host https://api.eu1.fullview.io).

## Specs
- [Bug Report OpenAPI](openapi/fullview-bug-report-openapi.yml): startBugReport, stopBugReport.
